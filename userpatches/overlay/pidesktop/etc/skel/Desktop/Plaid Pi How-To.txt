Plaid Pi 6.0 - Quick How-To
===========================


1. Getting Google Chrome
------------------------
Chromium is ready to use. Google Chrome isn't included, because Google's licence
doesn't allow it to be passed on, but it's a couple of clicks away:

  1. Click "Google Chrome" in the dock.
  2. Choose "Install". Chrome is downloaded straight from Google (about 120 MB).
  3. Type your password when asked.
  4. Choose "Make Default" if you want Chrome as your web browser.

Chrome then updates together with the rest of your software, and Plaid Pi
starts it with hardware video decoding switched on.

Installing Chrome also brings Widevine, the module streaming services use for
protected video. Chrome plays it right away; Chromium and Firefox (installed
from the dock) pick it up the next time you start them (Plaid Pi points them
at Chrome's copy; nothing is copied), so keep Chrome installed. Linux gets
Widevine's software level: the video is decoded by the processor, and each
service picks the quality (in our tests Netflix sent 1080p, Prime Video SD).


2. Firefox, LibreOffice, GIMP, Inkscape, Thunderbird and VSCodium
-----------------------------------------------------------------
These six are in the app grid (press the Super key and type the name), and
Firefox is in the dock too, but they download on the first click, so the
Plaid Pi image stays small:

  1. Click the app. Choose "Install" and type your password when asked.
  2. Wait for the download: LibreOffice about 120 MB, VSCodium about 160 MB,
     Firefox about 90 MB, Thunderbird about 75 MB, GIMP and Inkscape about 30 MB.
  3. The app opens by itself, and from then on it starts like any other app.

Firefox is set up for this board as it installs: it runs on the graphics chip
and, with a small library of Plaid Pi's, plays 8-bit and 10-bit video on the
board's video engine (H.264, VP9 and AV1 tested at 1080p). Chromium and Chrome
do too, and so does mpv, the video player, for files on your disk. LibreOffice
comes as Writer, Calc, Impress, Draw and Math; the database module isn't
included because it needs Java ("sudo apt install libreoffice-base" adds it).
VSCodium is the community build of VS Code with Microsoft's telemetry removed.
Everything updates through Pro Updates (and the daily security updates install
by themselves).


3. Screen scaling (how big everything looks)
--------------------------------------------
Settings > Displays > Scale

GNOME picks a scale for your monitor automatically - for example 125% on a
32-inch 4K screen. You can change it at any time.

Tip for 4K monitors at 120 Hz: in-between scales such as 125% or 150% make the
graphics chip work much harder, and video can stutter. For the smoothest video:

  - set Scale to 100%, and
  - if text is then too small, make it bigger with
    Settings > Accessibility > Seeing > Text Size
    That enlarges text without the extra graphics work.

The refresh rate is in Settings > Displays > Refresh Rate.


4. Films and music on a NAS (network drive)
-------------------------------------------
Videos opened straight from a network location in Files (smb://...) are read
a little at a time, so a film can skip for a moment when the NAS pauses.
Add the share as a network drive instead: the system then reads well ahead
for every program.

  1. In Files, click "Network", open the NAS and right-click the share (or an
     empty spot inside it) > "Add as Network Drive..."
     If the NAS isn't listed, type smb:// and its name in the "Server address"
     box at the bottom of the Network page and click "Connect" first.
     Or open "Network Drive" from the Utilities folder in the app grid and
     type the server and the share.
  2. Type your user name and password for the NAS (leave both empty if the
     share is open to guests) and choose "Add Drive".
  3. Type your own password when asked.

The drive then has its own entry in the Files sidebar; open films from there,
not from the Network page. It connects by itself when you open it and is also
under /mnt/ for other programs. mpv, the video player, keeps the most ahead.
To remove a drive, open "Network Drive", click the bin next to it, then
"Remove".
