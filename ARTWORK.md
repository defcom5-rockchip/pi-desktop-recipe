## Files

Paths are under `userpatches/overlay/pidesktop/`.

| File | What it is |
| --- | --- |
| `backgrounds/penguin-drop-plaid-v2-3840x2160.png` | Default wallpaper: penguins under plaid parachutes, 3840×2160 PNG. Installed at `/usr/share/backgrounds/pi-desktop/` and listed in Settings > Appearance by `backgrounds/pi-desktop-wallpapers.xml`. |
| `usr/share/pi-desktop/screensaver/plaid-penguin-drop.mp4` | Screensaver video: the penguin drop as a 60 s loop, 3840×2160, H.264, 30 fps, no audio. A build input (not in git; see `fetch-inputs.sh`). Installed at `/usr/share/pi-desktop/screensaver/` and linked into each new user's `~/Pictures/screensaver/`. |
| `fastfetch/plaid.ans` | The tartan "pi" terminal logo: truecolor half-block ANSI art, 36 columns × 21 rows, with the `PLAID PI / - 5 . 0 -` caption, shown by fastfetch on every new terminal. Generated by `fastfetch/plaid_logo.py`. |
| `usr/share/icons/hicolor/scalable/apps/pidesktop-get-code.svg`, `…-graphics.svg`, `…-mail.svg`, `…-office.svg`, `…-web.svg` | Placeholder app icons for the first-click installers (VSCodium, GIMP/Inkscape, Thunderbird, LibreOffice, Firefox): rounded navy square, cream glyph, orange download badge. Filled shapes only. |
| `branding/pi-desktop.svg` | The Plaid Pi logo: the Plaid tartan swatch (same sett, palette and twill as the terminal art) in the installer icons' rounded square, with a cream π in front. Generated by `branding/make-logo.py`; needs no font at render time. |
| `branding/pi-desktop-{16,22,24,32,48,64,128,256,512}.png` | PNG renders of the logo for the hicolor icon theme. |
| `branding/plaid-pi-logo-text.svg` / `.png`, `branding/plaid-pi-logo-text-dark.svg` / `.png` | The login-screen wordmark: the logo followed by "Plaid Pi" in DejaVu Sans Bold as filled paths, 400×64, charcoal text for light backgrounds and cream text for dark ones (the GDM greeter). Generated by `branding/make-wordmark.py`; the PNGs are librsvg renders. Installed in `/usr/share/pixmaps/`. |
| `branding/plymouth-bgrt-fallback.png` (256 px), `branding/plymouth-watermark.png` (128 px) | The logo rendered for the Plymouth boot theme. The recipe installs only the centred fallback image; the watermark file is kept for anyone who wants the small corner logo too. |
| `branding/preview.png` | Contact sheet of the logo at several sizes on light and dark backgrounds (for review, not installed). |
| `branding/pi-desktop.plymouth` | Plymouth theme descriptor: Ubuntu's `spinner.plymouth` (two-step) with the Plaid colours and the two images above. The animation frames are copied from Ubuntu's spinner theme at build time and are not in this repository. |
| `branding/make-logo.py`, `branding/make-wordmark.py` | Generators for the SVG logo, the renders, the preview and the wordmark. `branding/README.md` documents the construction (sett, twill, glyph, renderer) and places this directory, the scripts included, under CC BY-SA 4.0. |

The 4.0 Pro Updates icons (`pro-updates/facehugger.svg` and the refresh arrow written inline into
`install-pro-updates.sh`) left this repository with the Pro Updates scripts: since 5.0 Pro Updates is a package
from <https://github.com/defcom5-rockchip/pro-updates>, and the icon it installs (`pro-updates.svg`, a refresh and
download arrow drawn for that project) is part of that package under its GPL-3.0-or-later licence, not CC BY-SA
artwork of this repository.

## Third-party elements inside the artwork

- The **π glyph** in `branding/pi-desktop.svg` and the **"Plaid Pi" lettering** in the wordmark are outlines from
  **DejaVu Sans Bold**, converted to SVG paths by `make-logo.py` / `make-wordmark.py`. DejaVu is under the
  Bitstream Vera Fonts licence (with the DejaVu additions in the public domain), which permits embedding and
  derived works as long as the result is not sold as a font by itself. The logo therefore carries the Bitstream
  Vera notice in spirit: "Bitstream Vera is a trademark of Bitstream, Inc."; see
  <https://dejavu-fonts.github.io/License.html>.

## Not artwork

`backgrounds/pi-desktop-wallpapers.xml`, `fastfetch/config.jsonc` and the `.desktop` launchers are
configuration and fall under the recipe's GPL-3.0-or-later licence.

## Generators

- `branding/make-logo.py` regenerates the logo set; `branding/make-wordmark.py` the wordmark.
- `fastfetch/plaid_logo.py` regenerates `plaid.ans` (`python3 plaid_logo.py plaid.ans`); `make-logo.py` reproduces
  the same sett and twill for the logo.
- The script that renders `plaid-penguin-drop.mp4` is kept outside this repository.
