## Files

Paths are under `userpatches/overlay/pidesktop/`.

| File | What it is |
| --- | --- |
| `backgrounds/penguin-drop-plaid-v2-3840x2160.png` | Default wallpaper: penguins under plaid parachutes, 3840×2160 PNG. Installed at `/usr/share/backgrounds/pi-desktop/` and listed in Settings > Appearance by `backgrounds/pi-desktop-wallpapers.xml`. |
| `usr/share/pi-desktop/screensaver/plaid-penguin-drop.mp4` | Screensaver video: the penguin drop as a 60 s loop, 3840×2160, H.264, 30 fps, no audio. A build input (not in git; see `fetch-inputs.sh`). Installed at `/usr/share/pi-desktop/screensaver/` and linked into each new user's `~/Pictures/screensaver/`. |
| `fastfetch/plaid.ans` | The tartan "pi" terminal logo: truecolor half-block ANSI art, 36 columns × 21 rows, with the `PI DESKTOP 4.0 / - P L A I D -` caption, shown by fastfetch on every new terminal. |
| `usr/share/icons/hicolor/scalable/apps/pidesktop-get-code.svg`, `…-graphics.svg`, `…-mail.svg`, `…-office.svg`, `…-web.svg` | Placeholder app icons for the first-click installers (VSCodium, GIMP/Inkscape, Thunderbird, LibreOffice, Firefox): rounded navy square, cream glyph, orange download badge. Filled shapes only. |
| `pro-updates/facehugger.svg` | "Operation Facehugger" launcher icon for the Pro Updates tool (cartoon face-hugger on a charcoal disc with an orange ring). |
| `branding/pi-desktop.svg` | The Pi-Desktop logo: the Plaid tartan swatch (same sett, palette and twill as the terminal art) in the installer icons' rounded square, with a cream π in front. Generated by `branding/make-logo.py`; needs no font at render time. |
| `branding/pi-desktop-{16,22,24,32,48,64,128,256,512}.png` | PNG renders of the logo for the hicolor icon theme. |
| `branding/plymouth-watermark.png` (128 px), `branding/plymouth-bgrt-fallback.png` (256 px) | The logo rendered for a Plymouth boot theme. |
| `branding/preview.png` | Contact sheet of the logo at several sizes on light and dark backgrounds (for review, not installed). |
| `branding/pi-desktop.plymouth` | Plymouth theme descriptor: Ubuntu's `spinner.plymouth` (two-step) with the Plaid colours and the two images above. The animation frames are copied from Ubuntu's spinner theme at build time and are not in this repository. |
| `branding/make-logo.py` | Generator for the SVG, the renders and the preview. `branding/README.md` documents the construction (sett, twill, glyph, renderer) and places this directory, the script included, under CC BY-SA 4.0. |

## Third-party elements inside the artwork

- The **π glyph** in `branding/pi-desktop.svg` is the U+03C0 outline from **DejaVu Sans Bold**, converted
  to an SVG path by `make-logo.py`. DejaVu is under the Bitstream Vera Fonts licence (with the DejaVu
  additions in the public domain), which permits embedding and derived works as long as the result is not
  sold as a font by itself. The logo therefore carries the Bitstream Vera notice in spirit: "Bitstream Vera
  is a trademark of Bitstream, Inc."; see <https://dejavu-fonts.github.io/License.html>.
- The small **refresh arrow** written inline into `pro-updates/install-pro-updates.sh` (installed as
  `pro-updates.svg`) looks like a re-traced version of the Material Design "refresh" glyph (Google,
  Apache-2.0). Treat that one icon as Apache-2.0 rather than CC BY-SA, or replace it with an original
  shape before the release if a single licence for all icons is wanted.

## Not artwork

`backgrounds/pi-desktop-wallpapers.xml`, `fastfetch/config.jsonc` and the `.desktop` launchers are
configuration and fall under the recipe's GPL-3.0-or-later licence.

## Generators

- `branding/make-logo.py` regenerates the logo set.
- `fastfetch/config.jsonc` refers to a `plaid_logo.py` that produced `plaid.ans`; that script is not in
  this repository. `make-logo.py` documents the sett and twill it reproduces, so the tartan is specified
  even without it.
- The script that renders `plaid-penguin-drop.mp4` is kept outside this repository.
